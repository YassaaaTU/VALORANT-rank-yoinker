## Key Features Shown:

1. **Semi-transparent window** (90% opacity) with dark theme
2. **Title bar** showing current game state (INGAME, PREGAME, MENUS)  
3. **Toggle button** and hotkey indicator (F9)
4. **Drag handle** (≡≡≡ DRAG ≡≡≡) for repositioning
5. **Player information** with clean, readable formatting
6. **Team separation** to distinguish allies from enemies
7. **Comprehensive stats** including rank, RR, level, HS%, K/D, win rate

## Real Overlay Behavior:

- **Always stays on top** of other windows including games
- **Automatically updates** as new player data is received
- **Remembers position** when moved around the screen
- **Hotkey toggle** works from anywhere (F9 by default)
- **Smooth transparency** makes it unobtrusive during gameplay
- **Scrollable content** if there are many players
- **Color-coded ranks** for easy recognition
